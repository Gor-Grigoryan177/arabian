# Product photos

Drop real product photos here, then add the path to the product in
`lib/products-data.ts`:

    { id: 1, name: "Khamrah", ..., image: "/products/khamrah.jpg" }

The site automatically uses the photo instead of the generated bottle
illustration — no other code changes needed. Products without a photo keep
using the illustration, so you can add photos one at a time.

## Requirements

- Square or 3:4 portrait, at least 800px wide
- Transparent PNG or dark background (the site is dark themed)
- Use only photos you own or are licensed to use. Do not copy images from
  retailer or manufacturer websites.

## Where to get them

1. Ask your Lattafa / Afnan / Hayati distributor for official product images
2. Photograph your own stock
